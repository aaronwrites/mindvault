# Local fonts

Original, unmodified variable TrueType files from Google Fonts, used through `next/font/local`. Both fonts are distributed under the SIL Open Font License 1.1; the accompanying copyright and license notices are included here.

- [Lora source](https://github.com/google/fonts/tree/main/ofl/lora) — `lora-variable.ttf`, `Lora-OFL.txt`
- [Manrope source](https://github.com/google/fonts/tree/main/ofl/manrope) — `manrope-variable.ttf`, `Manrope-OFL.txt`

No runtime request to Google Fonts is required.
