# MindVault client

The MindVault client Captures a URL and optional Capture Context, presents Knowledge Item availability and organization condition, and supports Recall through grounded Passage excerpts.

## Run

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000). Configure `NEXT_PUBLIC_API_URL` when the API is not running at `http://localhost:4000`.
