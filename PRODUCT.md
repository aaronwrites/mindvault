# MindVault

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
People saving useful knowledge for later conceptual recall. Currently a solo developer's personal tool, portfolio project, and university project proposal.

## Product Purpose
Durably capture knowledge from links and files, organize it automatically, and retrieve it from vague conceptual memory without maintaining folders.

## Operating Context
The responsive library supports capture by link, paste, file selection, and drop; semantic search; evidence-grounded Ask; item details; title, tag, and note editing; and recoverable Trash. The user confirmed the full desktop and mobile library redesign must preserve these workflows.

## Capabilities and Constraints
Public textual webpages and retained PDFs support processing and retrieval. Other original files are retained without implying content understanding. Preserve availability, summary provenance, extraction coverage, and evidence disclosures. Use the existing Next.js, shadcn/ui, and local model stack; avoid unnecessary dependencies.

## Brand Commitments
MindVault is a personal visual collection with a warm editorial identity: ivory and charcoal surfaces, aubergine actions, self-hosted Lora headings, and Manrope reading text. Preserve calm responsive capture, retrieval, and evidence-grounded reading. The approved Warm Editorial Redesign supersedes previous red, outlined-panel, bouncing-status, and rotating-loading-text commitments.

## Product Principles
- Keep capture durable and distinguish saving from understanding.
- Make recognition and conceptual recall easy.
- Preserve evidence qualifications and honest processing states.
- Keep core tasks usable on desktop, touch, and keyboard.
