# Retain original files without becoming Google Drive

MindVault retains every user-uploaded Original File so it can be opened or downloaded later, while also extracting knowledge for previews, summaries, automatic organization, search, and future grounded answers. This storage promise does not expand MindVault into a general file-collaboration platform: folders are not required, and sharing, collaborative editing, device syncing, and similar Google Drive features remain outside the product boundary.
