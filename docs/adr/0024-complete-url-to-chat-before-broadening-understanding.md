# Complete URL-to-chat before broadening understanding

Prioritize a useful personal-use path from URL Capture through Extraction, automatic enrichment, Recall, and collection-wide grounded Synthesis before PDF/OCR, other file understanding, and additional organization features; this revises the delivery order in ADR-0019 because completing the product loop now is more valuable than deepening each capability in isolation. Informative source-provided metadata about the captured page is sufficient retrievable evidence when primary content is unavailable, revising ADR-0005's primary-text requirement while retaining its safe-access boundaries and ADR-0020's grounding contract. Evaluate a bounded extraction improvement against the user's five representative URLs, then proceed to chat without requiring every URL to yield evidence; defer browser workers, rare-site support, and polish while retaining durable Capture and honest availability.
