# Identify and version external Sources

MindVault treats normalized URLs, declared canonical URLs, and permanent redirects as strong evidence that captures refer to the same external Source. Content similarity may flag possible duplicates but never silently merges distinct Sources; when a Source changes, MindVault retains only meaningfully different cleaned Source Snapshots, deduplicated by content hash, with the newest primary-content snapshot current and older snapshots preserved as history. A newer metadata-only Snapshot is also retained and indexed with its limited coverage, but does not replace an existing primary-content current Snapshot; this prevents a reduced-evidence Refresh from degrading the user's active representation while preserving its provenance.
