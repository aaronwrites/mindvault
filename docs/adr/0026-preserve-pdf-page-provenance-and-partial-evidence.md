# Preserve PDF page provenance and partial evidence

Retain PDF evidence with Page References based on physical page positions counted from one, using printed page labels only as supplements, so citations remain resolvable despite cover pages or differing document numbering. A Knowledge Item may be Ready when only some pages yield trustworthy indexed evidence, with known unread or unprocessed pages disclosed through Extraction Coverage; this preserves useful knowledge rather than making one failed page invalidate the document. Extracted text, including OCR, supports textual claims but does not establish diagram, chart, or complex-table relationships, so partial availability must not imply complete document understanding.
