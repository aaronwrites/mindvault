# Library

Mode: Operate. Route: `/`. Primary target: `client/app/page.tsx`. Related targets: `client/components/`, `client/app/globals.css`.

## Direction contract

THESIS: A personal visual collection that invites revisiting saved knowledge and makes conceptual recall evidence-grounded.

OWN-WORLD: Warm ivory, white surfaces, charcoal text, muted stone, aubergine actions; warm charcoal and light plum in dark mode. Lora headings and Manrope reading/control text. The approved Warm Editorial Redesign replaces all earlier red, outlined-panel, status-bounce, gradient-reveal, and loading-slogan commitments.

FIRST VIEWPORT: Compact typographic wordmark, Ask/Add/menu, prominent memory search, always-visible All/Links/Files filters, and saved material. Paste/drop help sits beside Add; no standalone capture strip or redundant introduction in a populated collection.

FORM: Variable-height image, text, and document cards in an ordered responsive grid (1/2/3/4 columns at 0/640/1024/1280px). Search is a relevance-ordered evidence list. Missing media has a typographic treatment. Titles, source, textual availability, and organization exceptions remain visible.

DETAILS: Up to 1120px centered desktop overlay, full screen below 768px. Preview/source column beside summary, notes, tags, and expandable source details; no empty media frame. Title edit beside the heading. Provenance, partial extraction, and physical page citations remain close to the relevant content.

ASK: Right-side desktop companion and full-screen mobile conversation, anchored composer, session-only history and local-model disclosure. Citation details layer above the conversation; closing restores focus and conversation position.

CAPTURE: Compact Add dialog, durable success separate from processing, independent batch retries, duplicates, paste/drop protection, supported-understanding disclosure before selection. Existing API and lifecycle behavior define the scope.

TRASH: Plain list, restoration, confirmation before permanent deletion, pending cleanup and retry. Preserve Undo and search state on return.

INTERACTION: 12px cards, 10px controls, 20px desktop overlays, 44px touch controls, clear labels and focus. Short fades and restrained image scaling only, with reduced-motion support. Theme defaults to System and applies before paint.
